# HRMS

Multi-tenant SaaS Human Resource Management System.

## Architecture

- Backend: ASP.NET Core / C#
- Frontend: React + TypeScript
- Database: PostgreSQL
- Architecture: Modular monolith
- Tenancy: Platform database + database-per-tenant
- Infrastructure: Docker and AWS-compatible container deployment

## Development

The platform foundation is being developed in milestone-based increments. Business modules will be added only after the platform foundation is validated.
